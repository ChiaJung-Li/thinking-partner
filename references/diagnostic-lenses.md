# Diagnostic Lenses

Use these lenses to generate two to four candidate explanations when the user's dissatisfaction is vague. Select only lenses supported by the exchange; do not march through the full list.

## Framing and level

- **Wrong or narrow problem:** The response answers the stated question but misses the decision underneath it.
- **Abstraction mismatch:** The user needs strategy while the response gives tactics, or needs action while the response stays abstract.
- **Option-space mismatch:** The response compares the presented options without questioning whether those are the right options.

## Value and scope

- **Objective mismatch:** The response optimizes a result the user does not actually prioritize.
- **Time-horizon mismatch:** It favors an immediate outcome while ignoring compounding effects, reversibility, or future options.
- **Stakeholder or system omission:** It treats one actor in isolation even though incentives and constraints come from a broader system.
- **Hidden trade-off:** It presents an answer as simply better while suppressing a cost the user considers material.

## Consequences and evidence

- **Missing second-order effect:** The first result changes later incentives, positioning, dependencies, constraints, or option value.
- **Evidence mismatch:** The conclusion is stronger than the evidence, or the response treats correlation as causation.
- **Hidden criterion:** The user's reaction reveals a value or threshold not yet verbalized.

## How to diagnose without stalling

Ground candidates in contrasts the user can react to. For example: “I see two possibilities: the advice is too tactical because it optimizes getting this interview, or because it ignores the positioning you want to build across roles.” Ask at most one discriminating question when needed. If one interpretation is already well supported, name it provisionally and revise the answer rather than forcing a clarification round.
