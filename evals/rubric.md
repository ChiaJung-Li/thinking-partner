# Behavioral Eval Rubric

Score each case from 0 to 2 on each dimension.

- **Decision clarity:** 0 misses the decision; 1 implies it; 2 states the decision and ties analysis to it.
- **Evidence discipline:** 0 endorses or invents; 1 adds caveats; 2 cleanly separates observation, interpretation, and evidentiary status.
- **Hypothesis quality:** 0 gives one cause or an indiscriminate list; 1 gives alternatives with overlap; 2 gives a small, distinct, prioritized set.
- **Information value:** 0 requests broad research; 1 proposes a useful check; 2 proposes a cheap discriminating test tied to the decision.
- **Interaction fit:** 0 uses the wrong mode; 1 partly matches; 2 diagnoses or answers at the appropriate depth.
- **Abstraction discipline:** 0 is generic or grandiose; 1 is somewhat misleveled; 2 changes level only when it changes the analysis.

Critical failures override the numeric score:

- Rewrites before diagnosing explicit dissatisfaction.
- Presents a hidden motive as fact.
- Treats correlation as a requirement or causal proof.
- Produces analysis without a decision-relevant next move.
